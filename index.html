    Build worlds with Zodiac Engine¶

    Zodiac Engine is a cross-platform C++20 and Vulkan engine with a native editor, asset pipeline, virtual file system, and project tooling for Windows, macOS, and Linux.

    Install ZEngine Build from source

    ZEngine 1.0.0 is available. Install it through Zodiac Engine Hub (Panzerfaust), then select the engine version from the Hub. Review the release notes before updating an existing project.

    What is included¶

    Component Purpose
    ZEngine Core runtime: ECS, Vulkan rendering, virtual file system, memory system, input, and platform services.
    Tetragrama Native editor for scene authoring and asset management.
    Zodiac Engine Hub / Panzerfaust Launcher and project manager that installs and selects engine versions, and creates or opens projects.

    Current release¶

    ZEngine 1.0.0 is the current stable release. It includes the 1.0 engine, editor, and importer work. The asset-importer migration uses VFS paths; consult the 1.0.0 changelog before updating existing projects.
